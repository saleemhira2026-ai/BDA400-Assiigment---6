# BDA400 Assignment 6

## Technical Analysis Using R

This project develops an interactive stock portfolio dashboard using R and Shiny.

### Features

- Stock price visualization
- Date range selection
- Daily, Weekly, and Monthly time frames
- Moving Average indicator
- RSI indicator
- MACD indicator
- Buy, Sell, and Hold trading signals
- Buy and Sell annotations

### Tools Used

- R
- RStudio
- Shiny
- ggplot2
- quantmod
- Yahoo Finance
